# Mixed Messages

A Node.js console app that generates a random message each time it runs, built as Codecademy's [Mixed Messages](https://www.codecademy.com/paths/full-stack-engineer-career-path/tracks/fscp-javascript-syntax-portfolio-project/modules/fscp-mixed-messages/kanban_projects/mixed-messages) portfolio project (Full-Stack Engineer path, JavaScript Syntax section).

## About The Project

From the Codecademy project brief: build a message generator program that outputs a new, randomized message on every run, made up of at least three different pieces of data.

This implementation generates a random sentence for each character in the data using the template: *[Character] [Feeling] to [Action] [Object].*
